更新日志

记录每个版本的界面、功能和内容变化。当前版本：Beta v1.1。

Beta v1.1
Beta v1.12026-11-04
  • 自动扫描原 PPTX 中用反斜杠或斜杠标出的同义表达，把原来拆开的同义卡合并为一张主卡。
  • 同义表达分行显示，每个表达单独标注重音和逐词语法，不再放在注释里或单独占一张卡。
  • 合并后卡片总数从 228 调整为 226：第 1 课 57 张，第 3 课 51 张。
Beta v1.02026-11-03
  • 进入 Beta v1.0。
  • 一课最后一页点击“下一页”时，会先询问是否继续到下一课，并显示下一课名称；确认后自动进入下一课第一页。
  • 删除卡片页那一行的“编辑权限”按钮；编辑权限统一放到顶部快捷栏的“编辑”。
  • 顶部快捷栏全站保持一致：上一级、上一页、下一页、书首页、日志、编辑；不适用时置灰。
  • 整课浏览、学习计划、来源查询移到书首页的按钮区。
Alpha v2.22026-11-03
  • 来源卡片里的原句和“对话 / 全文”中，对应内容改为更明显的金色高亮，并自动滚动到高亮位置。
  • 对话和全文已转成文本附在来源旁边，可展开查看；旁边保留“查看原 PDF”。
  • 顶部快捷栏把“上一级”和“上一页/下一页”做成两个明显不同的区域；翻页收进“翻页”分组。
  • 课程下拉统一为“第 N 课 · 名称 · 张数”，修复第 4 课旧标题。
  • 删除旧的词组/句子类型代码、旧一级导航、旧单文件版、旧 UI 预览和旧包。
  • 去掉卡片里“原文拼写有误 / 语法错误”这类提示。
Alpha v2.12026-11-03
  • 新增卡片“来源”查询：显示书名、课次、第几个课文/对话、页码和原句。
  • 来源附原 PDF：可直接打开对应扫描页。
  • 新增全局“来源查询”页：按俄语/中文/标题查全部来源。
  • 来源会跟卡片一起保存、导出和恢复。
  • 新增顶部固定快捷栏：上一级、上一页、下一页、书首页、整课、计划、来源、编辑。
  • 顶部栏把“返回上一级”和“翻页”分成两个明显不同的区域；“上一张/下一张”改为“上一页/下一页”。
  • 三模式顺序调整为：顺序、复习、自定义。
  • 书首页、单元页、卡片模式统一读取同一份课程数据。
  • 修复：来源完整原文的 OCR 噪声不再直接铺开；只显示校对句，全文标为 OCR 初稿。
  • 卡片固定高度，翻页不跳动；编辑权限默认关闭。
Alpha v2.02026-11-03
  • 新增“书 → 单元 → 卡片”层级：新东方大学俄语（3）书首页。
  • 新增单元目录、单元整课浏览。
  • 新增顺序 / 自定义 / 复习学习计划。
  • 新增“默认打开本书”本地开关。
  • 新增编辑权限开关、返回上一级。
  • 卡片固定高度，编辑、导入、备份数据统一。

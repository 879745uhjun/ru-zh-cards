# 俄汉记忆卡 · Alpha v0.2

一个离线可用的俄汉对照记忆卡程序。俄语和中文分行显示；俄语逐词下划线，并在词下标注重音与语法现象。

## 打开方式

双击 `index.html` 即可在浏览器中使用，不需要安装依赖，也不需要联网。


## 只想用一个文件？

直接打开 `俄汉记忆卡-alpha-v0.2.html`。这是单文件浏览器版，CSS、JS、4 个课程和 187 张卡片全部内嵌，不需要文件夹，也不需要联网。

目录结构：

```text
ru-zh-cards/
├─ index.html          主页面
├─ styles.css          样式
├─ app.js              交互逻辑
├─ data/
│  ├─ deck.js          第 4 课 50 张（48 词组 + 2 句子）
│  ├─ lesson1.js       第 1 课 58 张
│  ├─ lesson2.js       第 2 课 27 张
│  └─ lesson3.js       第 3 课 52 张
├─ 俄汉记忆卡-alpha-v0.2.html  单文件浏览器版
├─ mockup.html         早期 UI 示意图（保留备查）

```

## 当前功能

- **三种模式**：对照 / 俄 → 汉 / 汉 → 俄。
- **逐词重音**：红色元音 + 尖音符；`ё` 自带重音；单辅音前置词 `в` 无独立重音，用虚线表示。
- **逐词语法**：每个俄语单词下方显示词性、性、数、格、动词体/时态/人称等。
- **学习模式**：
  - 默认关闭，所有语法直接显示。
  - 点击顶部“学习模式”后，语法隐藏；点击某个单词才显示该词的语法，再点一次收起。
  - 俄 → 汉和汉 → 俄两种模式都支持。
- **回忆模式**：
  - 俄 → 汉：先显示俄语，中文隐藏；点“显示中文”或按空格显示。
  - 汉 → 俄：先显示中文，俄语隐藏；点“显示俄语”显示俄语、重音、语法和提示。
  - 汉 → 俄未显示答案时，题卡标签会隐藏格信息，只显示“交通 · 回忆模式”等。
- **翻页**：上一张 / 下一张、页码跳转、键盘 `←` `→`、空格显示答案。
- **多课程**：顶部课程下拉切换；内置第 4 课（50）、第 1 课（58）、第 2 课（27）；支持新建、追加、替换、重命名、删除课程。
- **单卡编辑**：卡片右上角“编辑”，可改俄语、中文、分类、逐词语法和提示。
- **导入校验**：导入弹窗里点“校验”，检查卡片数、缺语法、缺重音和重复卡片。
- **完整备份 / 恢复**：导出全部课程 + 学习进度 + 复习计划；恢复备份会覆盖当前数据。
- **导入**：表格粘贴、JSON、文件导入；可追加、替换或新建课程。
- **本地保存**：导入后的词表保存在浏览器 `localStorage` 中；刷新不丢失。
- **导出**：可把当前词表导出为 JSON。
- **恢复**：一键恢复内置第 4 课词表；可清除全部学习进度。
- **记住上次位置**：刷新或下次打开时回到上次那张卡，并保留模式、学习模式、分类、随机和“只练复习”状态。
- **分类筛选**：按交通、旅游、景点、城市、文化、表达等分类筛选。
- **搜索**：按俄语、中文或分类关键词即时搜索。
- **随机顺序**：打乱当前筛选结果，避免总按顺序背。
- **学习进度**：每张卡可标记“已掌握”或“需复习”；顶部显示统计。
- **间隔复习**：“已掌握”默认 7 天后复习；“需复习”当天进入复习；每张卡显示下次复习日期。
- **今日复习 / 错题本**：“今日复习”只显示今天到期的卡；“错题本”只显示标记为“需复习”的卡。

## 导入格式

### 1. 表格粘贴

每行一张卡片，用 Tab 分隔：

```text
俄语	中文	逐词语法（可选）
```

示例：

```text
высокоскоростн[о]й п[о]езд	高铁	形容词 · 阳性单数 · 主格|名词 · 阳性单数 · 主格
сал[о]н красот[ы]	美容院	名词 · 阳性单数 · 主格|名词 · 阴性单数 · 属格
мен[я] ук[а]чивает	我晕车	代词 · 第一人称 · 宾格|动词 · 未完成体 · 现在时 · 第三人称单数
```

规则：

- 重音用方括号标出，例如 `чит[а]ет`；`ё` 自动视为重音。
- 用 `|` 分隔不同单词的语法，用 `/` 分隔同一个词的多个标签。
- 语法标签数量应与俄语单词数量一致；缺少时程序会提示。
- 可直接从 Excel 复制多行，粘贴到“表格粘贴”文本框。
- 导入前可点弹窗底部的“校验”，查看卡片数、缺语法、缺重音和重复卡片；校验不会修改现有数据。

### 2. JSON

可以粘贴卡片数组，或带 `title` / `cards` 的对象：

```json
{
  "title": "我的俄汉卡片",
  "cards": [
    {
      "ru": "чит[а]ть",
      "zh": "读",
      "tag": "动词",
      "note": "未完成体",
      "grammar": ["动词 · 未完成体 · 不定式"]
    }
  ]
}
```

也可以使用更明确的 `words` 数组：

```json
{
  "ru": "чит[а]ть",
  "zh": "读",
  "words": [
    { "text": "читать", "stress": 3, "grammar": ["动词 · 未完成体 · 不定式"] }
  ]
}
```

`stress` 是重音元音在单词中的下标，从 0 开始。

### 3. 文件

支持 `.json`、`.txt`、`.tsv`。JSON 按 JSON 解析，其余按表格解析。

## 关于语法纠正

按“只纠正错误，不改变原文正确语法”的原则处理课件内容：

- `на два недели` → `на две недели`：`неделя` 是阴性，数词应使用 `две`；数量“两周”不变。
- `культурные наследия`：课件为复数，按原文保留复数；卡片提示中注明更常见的单数表达是 `культурное наследие`。
- 其他词条保持课件原有单复数、格和搭配。

## 备份与恢复

- “导出备份”会生成一个 JSON，包含全部课程、学习进度、复习计划和当前课程。
- “恢复备份”会用备份覆盖当前全部课程和进度；恢复前会二次确认。
- “导出当前课程”只导出当前课程，不包含学习进度。

## Alpha 已知限制

- 没有语音朗读（按你的要求不做）。
- 间隔复习是轻量版：已掌握 +7 天、需复习当天；还不是完整的 SM-2 算法。
- 搜索范围是俄语、中文、分类，不包含语法提示正文。
- 搜索词本身不保存；分类、随机、今日复习、错题本和上次位置会保存。
- 表格导入以 Tab 为分隔符；从网页直接复制空格分隔的文本可能无法识别。
- 词表和进度保存在当前浏览器中；换浏览器或清理浏览器数据后会回到内置内容。
- 187 张卡片的重音和语法已人工标注，仍建议在使用中抽查；发现错误可直接用“编辑”修正，或改 data 文件后重新导入。
